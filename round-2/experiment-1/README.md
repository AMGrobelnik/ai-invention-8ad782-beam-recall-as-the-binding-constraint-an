## Layman Summary

We tested whether evaluating logic formulas across small example worlds helps pick the best natural-language-to-logic translation, versus simpler methods like taking the first answer or majority vote.

## Full Summary

This experiment implements and evaluates the Heterogeneous Oracle World Probing (HOWP) pipeline for FOL candidate selection, comparing 7 conditions across 100 synthetic NLI examples using LLaMA-3.1-70B as generator and Qwen-2.5-7B as oracle.

**Dataset:** 175 synthetic single/multi-premise NLI examples (50 beam recall, 100 main, 25 oracle validation) with controlled FOL structure. Labels: entailment (all X are Y + X(name) ⊨ Y(name)), contradiction (no X are Y + X(name) ⊭ Y(name)), neutral (some X are Y ⊭ Y(name)). Gold FOL in NLTK syntax for Z3 verification.

**Generator:** meta-llama/llama-3.1-70b-instruct (LINC-style few-shot prompt, k=5 candidates, temperature=0.7)

**Oracle:** qwen/qwen-2.5-7b-instruct (paid tier, free tier unavailable)

**Beam recall (k=5):** 100.00% — gate passed with high margin (threshold 60%)

**Oracle accuracy:** 77.33% (58/75 world-truth comparisons on pilot set)

**Condition results (100 examples):**
- howp_hetero (diagnostic worlds, Qwen oracle): 0.940 (94/100)
- howp_same (diagnostic worlds, LLaMA oracle): 0.940 (94/100)
- howp_random (random worlds, Qwen oracle): 0.960 (96/100)
- howp_m4 (diagnostic worlds m=4, Qwen oracle): 0.930 (93/100)
- top1 (first candidate): 0.950 (95/100)
- self_consist (edit-distance centroid): 0.950 (95/100)
- direct_judge (oracle picks best directly): 0.990 (99/100)

**Key comparisons:**
- howp_hetero vs top1: -0.01 (HOWP slightly below top-1)
- howp_hetero vs self_consist: -0.01 (HOWP slightly below self-consistency)
- diagnostic vs random worlds: -0.02 (random worlds surprisingly outperform diagnostic)
- hetero vs same oracle: 0.00 (oracle model identity makes no difference)
- m8 vs m4: +0.01 (more worlds slightly better)

**Key finding:** With beam recall = 100% and 70B generator, all methods perform similarly (0.93-0.99). World-probing (HOWP) does NOT outperform simpler baselines on simple predicate-application sentences. Direct oracle judgment (direct_judge = 0.99) outperforms all HOWP variants. The oracle's 77.3% in-distribution accuracy introduces noise that hurts HOWP selection relative to deterministic baselines.

**Total cost:** $0.0835 (well within $9 budget)
**Runtime:** 905 seconds (~15 minutes)

**Implementation:** Z3-based FOL model checker with NLTK syntax parser, async aiohttp client with oracle-sharing optimization (1 oracle call per world vs. n_candidates × n_worlds), batch processing with parallelism.
