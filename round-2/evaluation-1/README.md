## Full Summary

This evaluation artifact performs a complete statistical re-analysis of the Heterogeneous-Oracle World-Probing (HOWP) experiment run on the FOLIO validation dataset (204 examples, 7 prediction conditions).

**Metric 1 — Per-condition accuracy + bootstrap 95% CIs (10,000 resamples):**
- Hetero-Oracle (main): 20.6% [15.2%, 26.5%]
- Top-1 baseline: 19.6% [14.2%, 25.0%]
- Self-Consistency: 20.6% [15.2%, 26.5%]
- Direct-Judge: 20.1% [14.7%, 25.5%]
- Same-Oracle ablation: 24.5% [18.6%, 30.4%]
- Random-Worlds ablation: 23.0% [17.6%, 28.9%]
- m=4 ablation: 23.5% [18.1%, 29.4%]
All 7 conditions have widely overlapping CIs, confirming no condition is distinguishable.

**Metric 2 — McNemar's test (15 pairwise, BH-corrected):**
All 15 pairwise comparisons yield adjusted p-values of 0.77 (non-significant). Cohen's h effect sizes ≤ 0.14 for all pairs. Primary comparisons: hetero-oracle vs top-1 (p_adj=0.77, h=-0.105), hetero-oracle vs self-consistency (p_adj=0.77, h=-0.141), hetero-oracle vs same-model-oracle (p_adj=0.77, h=-0.058). No statistically significant or practically meaningful differences exist between any conditions.

**Metric 3 — Normalized self-consistency:**
Alpha-renaming bound variables before Jaccard clustering changed the selected candidate in 0% of examples. Normalized SC accuracy = 20.6%, delta = 0.0pp. The SC–hetero tie is genuine, not a variable-naming artifact.

**Metric 4 — Uncertain-class decomposition:**
69 gold-Uncertain examples exist. Main method predicted: 'Uncertain'=25 (coincidence hits), ''=41 (parse failure), wrong=3. 100% of the main method's Uncertain-class correct predictions are coincidence hits — none arise from genuine logical reasoning. Empty-string rates range 55–65% across conditions.

**Metric 5 — Cross-world agreement AUC:**
AUC-ROC = 0.660, Kendall τ = 0.212 (p=0.0009). The world agreement score provides a statistically significant, moderate discriminative signal consistent with the beam recall ceiling hypothesis. Mean max world score: correct=0.857, incorrect=0.742.

**Metric 6 — Inter-model agreement rate:**
Hetero and homo oracles select the same candidate in 77.5% of examples (158/204). When homo-oracle is wrong, hetero is correct only 5.8% of the time. Both correct=33, both wrong=145, only hetero=9, only homo=17.

All methods operate on the same ~20% accuracy floor set by FOL generation quality. A stronger FOL generator (≥60% beam recall) is necessary for the selection mechanism to have meaningful impact.
