## Full Summary

This research provides four concrete implementation blocks for the heterogeneous-oracle world-probing experiment.

**Block 1 — Z3 Python API for FOL Entailment**: The standard entailment check uses push/pop scoping: add premises, push, add Not(conclusion), check → if unsat → Entailment; pop, push, add conclusion, check → if unsat → Contradiction; else Neutral. Key Z3 primitives: DeclareSort('Domain'), Function(name, Domain, BoolSort()), Const(name, Domain), ForAll([x], Implies(...)), Exists([x], And(...)), Solver(), s.push()/s.pop(), s.check() == unsat. Critical discovery: LINC (Olausson et al. EMNLP 2023) actually uses Prover9 (not Z3) with NLTK logic module syntax; Z3 is our preferred choice due to Python-native integration.

**Block 2 — OpenRouter Pricing (verified 2026-06-09)**: meta-llama/llama-3.1-8b-instruct: $0.02/1M input, $0.03/1M output, 131K context. qwen/qwen-2.5-7b-instruct: $0.04/1M input, $0.10/1M output, 131K context. BONUS: qwen/qwen-2.5-7b-instruct:free exists (FREE, 131K, 2 providers). Total experiment cost at paid rates: ~$0.37, leaving $9.63 headroom under $10 cap. With free Qwen tier for oracle calls: ~$0.02–$0.05.

**Block 3 — Few-Shot FOL Prompt Template**: LINC uses HTML-style tags: <PREMISES>...<CONCLUSION>...<EVALUATE>TEXT: {nl}\nFOL: {fol}</EVALUATE>. FOL syntax is NLTK logic module: 'all x. (P(x) -> Q(x))', 'exists x. (P(x) & Q(x))', negation '-', conjunction '&'. Five verified NL→FOL example pairs extracted from LINC paper appendix and FOLIO validation data, with both NLTK syntax and Z3 Python API equivalents provided.

**Block 4 — Python FOL Model Checker**: Recommended approach is Z3-based (reuses existing dependency). Algorithm: DeclareSort for domain, add finite-domain axiom (ForAll x, Or of all named constants), assert ground atoms + CWA negations, then evaluate formula by checking if Not(formula) is unsat. Pure Python tuple-AST recursive evaluator also provided as fallback. Known edge cases: arity mismatch (most common LLM error), equality handling, CWA enforcement, domain finiteness constraint, XOR vs OR ambiguity.
