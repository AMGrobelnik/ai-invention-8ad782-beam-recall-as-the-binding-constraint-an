## Full Summary

This artifact prepares the FOLIO (First-Order Logic Inference and Ontologies) benchmark dataset sourced from tasksource/folio on HuggingFace (1,875 downloads, backed by Han et al. 2022). The dataset contains natural-language NLI problems where each example has a set of premises and a conclusion labeled entailment/contradiction/neutral, with gold FOL annotations.

**Dataset statistics:**
- Source: tasksource/folio (HuggingFace), mirroring Yale-LILY/FOLIO
- Total examples in full_data_out.json: 1,204 (203 validation + 1,001 train)
- Label distribution (validation): entailment=72, contradiction=62, neutral=69
- Each example includes: NL premises list, NL conclusion, normalized label, gold FOL annotations

**Stratified splits produced in data_out.json (410 examples):**
- Main experiment split (include_main=True): 252 examples — 84 per label, evenly distributed across quantifier complexity tiers (0/1/2)
- Beam recall split (include_beam_recall=True): 51 examples — ~17 per label, random seed 42
- Oracle pilot split (include_pilot=True): 30 examples — 10 per category A (simple predication), B (explicit negation), C (quantifier scope)
- Syntactic pre-filter: open_domain_existential flag applied; 0.5% filter rate

**Pilot worlds (pilot_worlds.json):**
- 90 hand-constructed minimal world models (3 per pilot example)
- Each world has: example_id, sentence, world_atoms, domain, ground_truth_bool, category, world_index

**Schema:** All examples in full_data_out.json conform to exp_sel_data_out schema. Input field contains premises + conclusion as a formatted NLI prompt; output field is the normalized label string. Metadata fields include: metadata_example_id, metadata_story_id, metadata_split, metadata_row_index, metadata_task_type (classification), metadata_n_classes (3), metadata_conclusion, metadata_num_premises, metadata_premises_fol, metadata_conclusion_fol.
